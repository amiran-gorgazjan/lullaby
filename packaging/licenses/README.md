# Dependency license supplements

Some locked crates omit license files from their published packages. The files
here preserve notices from their upstream repositories at the commits recorded
in each crate's `.cargo_vcs_info.json`. `overrides.json` pins the package name,
version, registry source, Cargo archive checksum, upstream commit, source URL and
SHA-256 of each supplement. These notices keep their upstream licenses.

`dispatch` 0.2.0 declares MIT and credits Steven Sheldon in its package manifest but
does not supply a separate license file upstream. Its supplement includes that
attribution and the standard MIT text, explicitly labeled as a supplement.

`r-efi`'s upstream `AUTHORS` contains its MIT grant and contributor notices; that
reviewed file is explicitly marked as license text in the pinned overrides.

`scripts/dependency_notices.py` verifies every registry `.crate` archive against
the exact external graph in `Cargo.lock` and reads the included texts directly
from those archives. It combines them with all applicable pinned supplements,
including extra contributor notices even when a crate supplies a license file.
It also requires the embedded egui default-font notices (including Hack) and
Lullaby's interface-font notices. Missing, stale or changed attribution fails
packaging. No source files or local cache paths appear in the generated notices.

Generate notices offline after `cargo fetch --locked`:

```sh
python3 scripts/dependency_notices.py \
  --output target/beta-notices/THIRD-PARTY-NOTICES.txt \
  --manifest target/beta-notices/manifest.json
```

The full lock graph is included, covering build tools and other platforms.
Including alternative license texts does not require accepting all alternatives
and does not license Lullaby's own code. The release packager separately retains
the current project license and previously published MIT baseline notices.
The AU wrapper's CLAP, AudioUnitSDK and fmt notices are generated by the AU build
and retained in its component resources. Updating dependencies requires
reviewing missing or changed notices before distributing new downloads.
