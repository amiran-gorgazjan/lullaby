Lullaby is a free, open-source adaptive resonance suppressor, released under MIT.

- VST3 and CLAP for Windows and Linux (x86-64).
- VST3, CLAP and AUv2 for macOS (universal Intel + Apple Silicon).
- Gentle defaults, frequency weighting bands, sidechain, delta monitoring,
  mid/side processing, presets, and a scalable native interface.
- Regression coverage for resonance detection, audio reconstruction, host
  parameter handling, real-time allocation behavior, and bounded Rust memory.

Download the ZIP for your OS below, extract it, and follow `INSTALL.md`.
The `.sha256` files provide archive checksums. Source archives are also available.
The private vocal test recordings are excluded; the public tests use synthetic
signals. No activation or payment is required.

This is an early release. macOS downloads are ad-hoc signed and not notarized.
Automated builds and smoke tests do not replace testing in every DAW. The plugin
introduces latency (42.67 ms in Normal quality, 10.67 ms in Low latency at 48 kHz).
Lullaby has an original DSP engine and is unaffiliated with oeksound; sonic
equivalence with Soothe is not claimed.
