# Interface fonts

These unmodified fonts are embedded in the editor, so the same typography renders
on Windows, macOS and Linux without installing fonts or accessing the network.

- Cormorant Garamond variable font, used at weight 650 for the wordmark:
  [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond).
  Copyright 2015 the Cormorant Project Authors. See `CormorantGaramond-OFL.txt`.
- Lato Regular, used for controls:
  [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/lato).
  Copyright 2010–2014 tyPoland Łukasz Dziedzic. See `Lato-OFL.txt`.

Both are licensed under the SIL Open Font License 1.1. The bundle task copies the
full copyright and license notices into bundle resources and includes a companion
`FONT-LICENSES.txt` for distributions containing a single-file CLAP. Keep that
notice with Windows/Linux CLAP distributions. AU resources include both notices.
